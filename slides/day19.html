K-means: the goal

The same 150 points, two ways to make K = 3 clusters. Which is better?

  • Pick \(K\). Each centroid (×) is the average of its cluster’s points.
  • W adds up the squared line lengths: \(\sum_k \sum_{i \in C_k} \sum_j (x_{ij} - \bar{x}_{kj})^2\).
  • K-means looks for the clusters with the smallest W.

Can’t we just try every split?

  • 150 points into 3 groups: about \(10^{70}\) ways. Too many.
  • Instead (ISL Algorithm 12.2):
    1. Put each point in a cluster at random.
    2. Compute each cluster’s centroid.
    3. Move each point to the closest centroid.
    4. Repeat 2–3 until no point moves.

Step 1: random clusters

  • Each point gets cluster 1, 2, or 3 at random. W = 1979.

Step 2: compute the centroids

  • × = each centroid. Random clusters put all three near the middle.

Step 3: move to the closest centroid

  • Each point takes the color of the nearest ×. W: 1979 → 1123.

Repeat until nothing changes

  • The centroids walk out to the groups. After 4 rounds, no point moves.
  • W never goes up: each step can only shorten the lines.

Each start can end differently

  • K-means can stop at a worse split. 14 of 300 random starts got stuck:

  • Fix: try many starts, keep the smallest W (nstart = 20).

K-means in R

set.seed(19)                                 # the starts are random
km <- kmeans(blobs[, c("x1", "x2")],         # numeric columns only
             centers = 3,                    # K

How many clusters?

  • More clusters always lower W. With \(K = n\), W = 0.
  • Look for the elbow: big drops up to K = 3, small ones after.

What K = 6 does

  • W falls (283 → 167), but each real group is just cut in two.
  • Choosing \(K\) is a judgment call: the elbow, plus the use.

Units matter

300 shoppers: age (years) and income (dollars). K = 3.

  • Raw: $1,000 counts as much as 1,000 years. K-means only sees income.
  • Standardized: both columns count. Three clear groups.

Standardize first

  • Distances depend on units (KNN on Day 13, k-means today).
  • scale() puts each column in SDs: (x − mean) / SD.
km <- kmeans(scale(shoppers), centers = 3, nstart = 20)
  • Skip it only if the units should count (the cities: both in degrees).
